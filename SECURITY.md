# Security policy

Сообщайте об уязвимостях приватно через раздел **Security → Report a vulnerability**
репозитория GitHub. Не публикуйте рабочий exploit в открытом issue до исправления.

popingui слушает только loopback (`127.0.0.1`). WebSocket принимает браузерные соединения
только от интерфейса приложения и локального Vite-сервера. Указанные пользователем цели
и учётные данные прокси хранятся локально в каталоге данных приложения.

Поддерживается последняя опубликованная версия.
