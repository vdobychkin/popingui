# Changelog

Все заметные изменения проекта документируются здесь. Формат основан на Keep a Changelog,
версии следуют Semantic Versioning.

## [Unreleased]

## [1.0.1] — 2026-09-01

- Подготовлен воспроизводимый Windows-релиз через GitHub Actions.
- Добавлена русская и английская документация и снимок интерфейса.
- WebSocket ограничен доверенными loopback-origin.
- Проверка планировщика больше не зависит от свободного порта 8000.
- Electron и инструменты сборки обновлены до версий без известных npm-уязвимостей.

## [1.0.0] — 2026-08-25

### Добавлено

- Многослойная диагностика DNS, PING, TCP, TLS/SNI, HTTP и UDP/QUIC.
- Массовый мониторинг, история задержки и расчёт доступности.
- SOCKS4a, SOCKS5 и HTTP CONNECT, включая SOCKS5 UDP ASSOCIATE.
- Windows-приложение с треем, уведомлениями, автозапуском и экспортом CSV/JSON.
- Двенадцать локальных regression-проверок сетевой логики и планировщика.
